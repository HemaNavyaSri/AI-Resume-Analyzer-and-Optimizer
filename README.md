# AI Resume Analyzer and Optimizer

AI Resume Analyzer and Optimizer is a Flask-based web application that helps users analyze their resume against a job description and generate a job-tailored resume.

## Features

### Resume Analyzer
- Upload PDF resume
- Enter a job description
- Extract text from the resume
- Calculate resume-job match score
- Calculate skill match score
- Detect skills in the resume
- Detect skills required by the job description
- Identify matching skills
- Identify missing skills
- Provide recommendations

### Resume Optimizer
- Enter personal information
- Enter education, projects and experience
- Enter existing skills
- Paste a job description
- Automatically detect relevant technical skills
- Generate a job-tailored resume
- Download the resume as a PDF

## Technologies Used

- Python
- Flask
- NLP
- TF-IDF
- Cosine Similarity
- PyPDF2
- Scikit-learn
- ReportLab
- HTML
- CSS
